# VirtualPLC

Mitsubishi MC/SLMP virtual PLC simulator research and test-driven development.

**Status:** M1 development; local-only 3E Binary/TCP D/M prototype. **NOT for industrial control, production PLC networks, or safety-critical use.** Vendor-specific behavior and full `pymcprotocol` compatibility are not yet verified.

Development documents, tests and source will be proposed on a dedicated branch/PR. See that PR for the runnable M1 prototype and its quality gates.
